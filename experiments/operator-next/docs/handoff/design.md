# A conversation that opens into the data

The rejected lab is not visual authority. This fresh interface uses a cool white operations workspace with restrained indigo actions, charcoal text and green/amber only for operational condition. Manrope variable provides a compact, readable type rhythm. Quiet sidebar groups navigation and history; the content occupies the page instead of redundant application headers and a comparison toolbar.

The signature interaction is an inline mini-app becoming an optional focus view of the same immutable result. Users retain a clear route back, scoped conversation and exact evidence. First entry is an explicitly labelled example investigation, so the generative experience is visible without fake user activity. New conversations start empty. Three real destinations—Assistant, Assets, Saved views—support both natural-language and direct browsing.

Inline cards use a short meaningful title, one scope line, working controls and the artifact itself; avoid duplicate heading/status/source banners. A source tray shows quotations and record provenance on demand. Focus view gives maps/charts useful space while keeping the composer. New follow-ups do not silently replace the focused result. Saved definitions are named read recipes, not old rendered answers.

Palette: #FFFFFF surface, #FAFBFC canvas, #F6F7F9 sidebar, #202735 ink, #667184 secondary, #E6EAF0 separators, #4059D9 action. No gradients, branded hero, decorative metrics, nested card towers or fake controls. Font sizes 12/13/14/16/20/30. Internal table overflow rather than horizontal page overflow. Native dialog focus/escape, real buttons, reduced motion and source text rendered as text.
